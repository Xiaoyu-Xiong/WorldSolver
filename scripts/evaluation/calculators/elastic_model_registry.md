# material.elastic_law.v1 fixed model registry

This calculator is a constitutive check, not a trajectory force-balance check.
Targets are computed from geometry and the following fixed energies. It never
uses actual stress/force/couple to construct a target. The scaffold must select
the model, reference data, material assignments, scales, and applicability rules
before simulation. Cross-frame checks detect drift, but cannot authenticate a
solver-authored first frame against a scaffold that was not supplied to compute.

## IDs, widths, parameters

Numeric IDs and column orders below are frozen for v1. There are **no defaults**
for material values, thickness, natural configuration, orientation, or scales.
`material_model_id[Me]` contains these IDs; `element_material_id[Ne]` contains
zero-based **row indices** into that table, not model IDs.

| ID | Representation | Model | Required ordered columns | Width |
| --- | --- | --- | --- | --- |
| 1 | volume | Compressible logarithmic neo-Hookean | lambda [Pa], mu [Pa] | 2 |
| 2 | volume | St. Venant–Kirchhoff (StVK) | lambda [Pa], mu [Pa] | 2 |
| 3 | volume | Infinitesimal linear elasticity | lambda [Pa], mu [Pa] | 2 |
| 101 | rod | Geodesic-midpoint Cosserat edge | GA1 [N], GA2 [N], EA [N], EI1 [N m²], EI2 [N m²], GJ [N m²] | 6 |
| 201 | shell | Plane-stress StVK membrane plus dihedral hinges | Young's modulus E [Pa], Poisson ratio nu [1], thickness h [m] | 3 |

`material_parameters` is a finite real rectangular `[Me,Qp]` array. `Qp` must
accommodate every row's required width. Extra columns must be **exactly zero**;
they are padding, not extra model parameters. For example a universal width of
6 uses `[lambda,mu,0,0,0,0]`, `[GA1,GA2,EA,EI1,EI2,GJ]`, or `[E,nu,h,0,0,0]`.
A single call has one representation; rows of other representations are errors,
even when unused. Unknown IDs, nonintegral IDs, nonfinite entries, short rows,
and nonzero padding are errors. The registry is immutable; no expression or
callable supplied by a solver is accepted.

Volume requires `mu>0` and `lambda+2*mu/3>0`; lambda can be negative for auxetic
materials. All six rod stiffnesses must be strictly positive. Shell requires
`E>0`, `h>0`, `-1<nu<0.5`. Rod stiffnesses are already integrated over the cross
section; no implicit radius, area, circular-section assumption, or factor of
thickness is applied. Material axes 1 and 2 describe transverse shear/bending,
and axis 3 describes extension/twist. Anisotropic rod bending is supported.

## Input and frame contract

`compute(frames, inputs, parameters)` returns `CalculatorResult` with one finite
nonnegative scalar error per evaluated frame, including the first frame when
active. An integer `frame_indices` array explicitly maps every error to its
original frame index; validated fully inactive frames are skipped, never filled
with zero. At least one evaluable frame is required. Times must be finite,
nonnegative, and strictly increasing, including skipped frames. The only
parameters are required `representation=volume|rod|shell` and
`reference_source=frozen_material_model`, as generated by new055–154 YAMLs.
All input names and paths follow `generate_task_yamls.py` without changes.

Common inputs are `material_model_id`, `material_parameters`,
`element_material_id`, and binary `active_mask[Ne]`. Every bound value must be
present, real, finite, and correctly shaped, including inactive entries.

Volume uses `deformation_gradient[N,3,3]`, `first_piola_stress[Ne,3,3]`, and scalar
`reference_stress`. **N must equal Ne in the same element order.** This v1
implementation has no optional mapping input and never broadcasts. Export a
pure per-element trajectory or explicitly adapt/reorder both arrays before
evaluation; mixed nodal/element data cannot be scored as supplied.

Rod and shell use `position[N,3]`, `reference_position[N,3]`,
`elastic_force[N,3]`, scalar `reference_force`, and integer `topology[Ne,2]`
(rod edges) or `[Ne,3]` (shell triangles). Rod also requires current
`orientation[N,4]`, `reference_orientation[N,4]`, `elastic_couple[N,3]`, and
scalar `reference_torque`. Quaternions are unit xyzw, rotating material vectors
into world coordinates; no quaternion components are differentiated directly.
Shell has **no independent rotational DOFs or couple input** in these YAMLs:
bending moments enter the translational nodal forces through hinge energy.

Every reference scale is scalar, strictly positive, finite, and exactly constant
across the call. Model ID arrays and material parameter tables are also frozen.
Reference positions and reference quaternions allow **append-only rows**: the
complete prefix exported in the previous frame must remain bitwise identical
after conversion to float64, including signed zeros. New reference rows become
frozen immediately, even when appended in an inactive frame. Current positions,
forces, orientations, and couples must all match the new node count. A cut may
append duplicate nodes with inherited reference positions/material frames and
retarget topology to their new global indices. Existing rows must never be
removed, moved, or reassigned; a preallocated stable node pool is also supported.
The scaffold/adapter is responsible for authenticating inherited reference data:
these YAMLs do not supply a parent-node mapping for verifying new rows' provenance.

Persistent elements cannot change material row: volume identity is the aligned
array index; rod/shell identity is the set of incident global node indices.
Volume therefore requires a **stable append-only element index pool**: its row
count cannot decrease, all existing material assignments remain frozen, and
removed elements stay in the arrays with mask zero. New elements may append.
Reindexing or reuse of a deleted slot is forbidden; exchanging two elements
with the same material cannot be detected without persistent element IDs, which
the YAMLs do not provide. The trusted adapter must enforce that identity rule.
Rod/shell topology may add or remove actual connections and reorder element
rows while retaining global node identities and persistent material assignments.
Quaternion sign changes in current frames are harmless; reference arrays must
retain their frozen values. Arbitrary remeshing/reindexing requires a separately
frozen evaluation segment rather than silently changing material references.

## Volume energies and stresses

Energies are per unit reference volume, `J=det(F)>0`, `I` the 3D identity:

* ID 1: `Psi = mu/2*(tr(F^T F)-3) - mu*log(J) + lambda/2*log(J)^2`.
  `P = mu*(F-F^-T) + lambda*log(J)*F^-T`.
* ID 2: `Egreen=(F^T F-I)/2`,
  `Psi=mu*tr(Egreen²)+lambda/2*tr(Egreen)^2`,
  `P=F*(2*mu*Egreen+lambda*tr(Egreen)*I)`.
* ID 3: `epsilon=(F+F^T)/2-I`,
  `Psi=mu*tr(epsilon²)+lambda/2*tr(epsilon)^2`,
  `P=2*mu*epsilon+lambda*tr(epsilon)*I`.

IDs 1 and 2 are objective under finite superposed rotations. ID 3 is explicitly
an infinitesimal-strain model: it is **not** objective for finite rotations and
must not be selected for large-rotation experiments. No corotational behavior
is silently substituted. Inversion or singular F on an active element is an
error for all three models; finite inverted data may be excluded by a frozen
applicability mask. StVK also has its usual large-compression limitations; it
is not a general-purpose inversion-safe material.

## Rod energy and world-space virtual work

For directed edge `(i,j)`, reference length `L=|Xj-Xi|>0`, material-to-world
frames `Ri,Rj`, principal rotation vector `a=Log(Ri^T Rj)`, define
`Rmid=Ri Exp(a/2)`, `gamma=Rmid^T (xj-xi)/L`, and `kappa=a/L`.
Compute `gamma0,kappa0` using the reference positions and reference frames by
the **same definitions**. Thus natural curvature, twist, and shear are encoded
by the complete natural configuration, not by an assumed straight centerline.

`Uedge = L/2 * [sum(Ks*(gamma-gamma0)^2) + sum(Kb*(kappa-kappa0)^2)]`,
where `Ks=(GA1,GA2,EA)` and `Kb=(EI1,EI2,GJ)`. Sum over surviving active edges.
This is the fixed discrete model; it does not claim equivalence to every rod
solver's interpolation or quadrature. It includes stretching, two shear modes,
two bending modes, and twist. It is objective under `x->Qx+t, R->QR`.

`fi=-dU/dxi`. The world couple `ci` is defined by
`Ri(epsilon)=Exp(epsilon*[world_axis]_cross) Ri`, `ci=-dU/d epsilon`.
Consequently `delta U=-sum(fi dot delta xi+ci dot delta theta_world)`.
Shear-frame dependence contributes to couples as well as curvature/twist; a
pure bending/twist target is never replaced by zero. Forces and couples are
assembled at all incident nodes before selecting evaluable nodes. Quaternions
must be unit to absolute norm tolerance `1e-8`. Relative rotations within
`0.01 rad` of the principal log's pi branch are rejected (including probe states);
refine the mesh. This representation cannot recover multiple turns per edge.

## Shell energy, topology, and bending

Each triangle uses an orthonormal reference tangent basis and a reference edge
matrix `Dm` in that basis. `Fsurface=[x1-x0,x2-x0] Dm^-1` is 3x2;
`Egreen=(Fsurface^T Fsurface-I2)/2`. With reference area `A0`,
`mu2=E/(2*(1+nu))`, `lambda2=E*nu/(1-nu²)`,

`Umembrane=A0*h*(mu2*tr(Egreen²)+lambda2/2*tr(Egreen)^2)`.

Membrane forces use the analytic derivative. Bending is assembled once per
interior edge; a free boundary edge has no hinge. Triangles must be consistently
wound and edge-manifold; repeated vertices and duplicate elements are errors.
For directed shared edge `(i,j)` with triangles `(i,j,k)` and `(j,i,l)`,
`theta=atan2(t dot (n_left cross n_right), n_left dot n_right)` with unit current
edge tangent `t` and unit oriented triangle normals. `theta0` is the same angle
in the reference geometry. Let `delta=wrap_to_[-pi,pi](theta-theta0)`,
`Dside=Eside*hside^3/(12*(1-nuside²))`, and

`Uhinge = 1/2 * ((Dleft+Dright)/2) * L0²/(A0left+A0right) * delta²`.

This explicitly frozen hinge discretization uses the arithmetic mean of adjacent
bending rigidities. Its coefficient is part of model 201, not a freely chosen
solver convention or a claim of exact equivalence to all continuum shell
quadratures. The nonzero natural dihedral is stress-free. Forces differentiate
all four hinge positions, including the edge endpoints. Membrane and hinge
forces are added. The energy is objective under any common proper rigid motion.
Folds within `0.01 rad` of the wrapped displacement's pi branch are rejected.
Collapsed edges/triangles and relative triangle sine below `1e-12` are errors.

## Masks and normalization

Fully inactive frames are skipped **only after** validating all finite values,
shapes, material IDs/parameters, scalar scales, topology indices/manifoldness,
quaternion norms, and frozen/append-only metadata. An initially empty node or
element pool is permitted with correctly shaped empty arrays and a nonempty
frozen material table; later frames may append to it. Existing node and volume
element pools still cannot shrink. Geometry derivatives and
positive-J checks apply only to active elements. An entirely inactive dataset
is an error, never an empty result or synthetic zeros. Volume scores all active stress components.
Discrete force fields are understood as full actual nodal elastic forces.
An evaluable node must touch an active element and have no incident inactive
element. For shell, all four nodes of a hinge touching an inactive triangle are
also excluded, because its omitted force is unknown. Isolated nodes are ignored.
If active elements exist but no complete active neighborhood remains, evaluation
errors rather than hiding a partial-neighborhood dataset as inactive. This avoids
comparing the derivative of only part of the elastic energy to a full nodal
force. Topology must retain excluded incident elements to identify such
neighborhoods unless those elements have actually been removed from the solver.

For each frame, volume error is the RMS of all components of
`(Pactual-Pexpected)/reference_stress`. Shell uses force components divided by
`reference_force`. Rod concatenates these force components with world-couple
components divided by `reference_torque`, and takes one RMS. Cartesian component
averaging avoids cancellation between different nodes/elements. No magnitude
of actual data or current energy is used to enlarge the frozen denominator.

## Numerical differentiation and performance

Volume, membrane, and rod translational derivatives are analytic. With
`n=Rmid*(Ks*(gamma-gamma0))`, the rod endpoint forces are `(n,-n)`.
World-rotation derivatives use the chain rule on the **same fixed energy**:
`c=-L*(K*strain) dot d(strain)/d(theta_world)`. Differentiate the six-component
strain vector by five-point probes, then contract with the analytic energy
gradient. This avoids subtracting large probe energies from unstressed shear
modes to recover a tiny twist response. It does not change the constitutive
model or discard shear-frame couples. Each rod edge needs 24 strain probes.

Hinge translations use a five-point symmetric energy derivative:
`f = (U(+2h)-U(-2h)-8*(U(+h)-U(-h)))/(12h)`.
The dimensionless step is machine-epsilon^(1/5), balancing roundoff and fourth
order truncation. Hinge translation probes use
the minimum local reference/current edge and current hinge-altitude scale.
Rotational probes use the dimensionless step in radians. Local coordinates
are recentered before differentiating, so a world translation does not enlarge
the probe. Extreme deformation or ill-conditioning may still lose precision;
normalization scales do not tune or hide that numerical error.

Each hinge requires 48 energy probes plus one reported-energy evaluation.
Work and storage are linear in mesh
size per frame, with a substantial Python/SciPy constant factor. This is an
offline constitutive diagnostic, not a real-time solver. No global dense
Hessian, whole-scene differencing, or scene-specific physics is used. Probe
overflow, singular geometry, and nonfinite residuals raise errors. Very large
translations can already destroy geometric precision in the exported doubles;
recentering cannot restore lost input digits. Frozen normalization scales should
reflect the physical modes being scored: rod force scales may need both axial
stiffness `EA` and bending scale `EI/L²`, while torque uses its own scale. A force
scale arbitrarily far below floating-point axial-force precision cannot yield
an accurate normalized diagnostic, even if the small torque is well resolved.

Tests cover independent volume energy derivatives and analytic stresses; rod
extension, shear (independent scalar virtual work and moment balance), natural
bending, finite bending/twist and world couples; a general noncommuting-rotation
SLERP energy oracle independent of production helpers;
analytic membrane and nonzero folded-hinge forces; superposed finite rotations;
scale changes; nonzero perturbations; exact YAML input bindings; frozen metadata;
append-only cut-node references and volume pools; validated inactive frame
mapping; invalid shapes, values, topology, empty masks, and missing inputs. Integration
into the calculator registry is intentionally left to the owning integration task.
